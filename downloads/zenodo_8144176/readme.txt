The deposition consists of 262 allosteric kinase inhibitors and activators with experimentally determined binding model determined binding mode. For each inhibitor, the PDB ID, ligand ID, CHEMBL ID, target ID (UniProt), kinase group,protein kinase name, SMILES for inhibitor structure and mechanisms of mode are reported. For a compound containing a privileged substructure (PS), the SMILES string of the PS is also provided. In adition, for each compound, the binding pocket and inibitor type (III or IV; if available) are reported.
